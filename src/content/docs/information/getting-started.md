## Requirements

Before installing, make sure your server meets the following requirements.

| Requirement                          | Version |
|--------------------------------------|---|
| OS                                   | Ubuntu 22.04+ / Debian 12+ |
| Node.js                              | 18+ |
| Nginx / Apache / Caddy / Cloudflared | Any recent |

## Picking a Server OS

Vessel runs on any modern Linux distribution. Ubuntu 22.04 LTS and Debian 12 are the recommended options for production use.

> **Note:** Vessel does not support OpenVZ-based systems due to Docker incompatibilities.
